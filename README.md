# STUDENT-COURSE-MANAGEMENT-SYSTEM
STUDENT COURSE MANAGEMENT SYSTEM – SQL PROJECT

The Student Course Management System is a database project designed to efficiently manage and track information related to students, courses, and their enrollments. It provides a structured way for educational institutions to store student details, course offerings, and the grades received by students in various courses.

This project is fully built using SQL and demonstrates essential database concepts such as table creation, data insertion, primary & foreign keys, joining tables, data retrieval, and analysis using SQL queries.

The system contains three main tables:

Students – stores personal and academic details of students

Courses – stores information about available subjects and their credit values

Enrollments – acts as a bridge table mapping students to courses, along with grades

The project showcases a real-world many-to-many relationship between students and courses. It enables users to perform essential academic operations such as viewing enrolled students, analyzing student performance, generating grade reports, and understanding course popularity.

This SQL project is simple, scalable, and demonstrates strong database design and querying skills suitable for academic submissions, beginner database practice, and resume-worthy SQL experience.
